Политика конфиденциальности

Черновик документа для разработки сайта. Перед публикацией сайта текст должен проверить и утвердить юрист компании с учётом фактического состава собираемых данных и требований 152-ФЗ.

1. Общие положения

Настоящая политика определяет порядок обработки персональных данных посетителей сайта sofit.example (далее — «Сайт») компанией «Софит» (далее — «Компания»).

2. Какие данные собираются

При заполнении формы обратной связи на странице «Контакты» Компания получает: имя, телефон, при желании — название компании, e-mail и текст комментария. Отправка формы возможна только при отдельном согласии на обработку персональных данных.

Сайт может также автоматически получать технические данные (IP-адрес, тип браузера) — это стандартная информация, которую браузер передаёт любому веб-серверу при заходе на страницу.

3. Цели обработки

Данные из формы обратной связи используются исключительно для связи с обратившимся человеком по вопросу его заявки — консультации, расчёта стоимости, обсуждения проекта.

4. Передача третьим лицам

Компания не передаёт персональные данные посетителей сайта третьим лицам, кроме случаев, прямо предусмотренных законодательством РФ.

5. Хранение и удаление

Данные хранятся до момента, пока не утратят необходимость для целей обработки, либо до отзыва согласия. Для отзыва согласия и удаления данных можно обратиться по контактам, указанным на странице «Контакты».

6. Изменение политики

Компания может обновлять эту политику. Актуальная версия всегда доступна на этой странице.
